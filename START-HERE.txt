PerfScope 试用说明
==================

PerfScope 用来测 App 的性能：连上手机后，实时采集 CPU、内存、FPS、流量、电量等指标，每秒截一张屏，
测完上传到团队服务端，大家可以一起看、做版本对比。支持 Android 和 iPhone。

团队服务端（看所有人上传的测试）：{{SERVER_URL}}
需要和服务端在同一网络（公司 Wi-Fi / VPN）才能打开和上传。


一、准备（只需一次）
-------------------
1. 安装 Python 3.10 或更新版本
   macOS：在终端运行  brew install python@3.12
          （没有 Homebrew 的话从 https://www.python.org/downloads/ 下载安装）
   Windows：从 https://www.python.org/downloads/ 下载安装，安装时勾选 "Add python.exe to PATH"

2. 测 Android 手机：安装 adb
   macOS：brew install android-platform-tools
   Windows：从 https://developer.android.com/tools/releases/platform-tools 下载解压，把目录加入 PATH
   手机打开「开发者选项 → USB 调试」，连上电脑后在手机上点「允许」，USB 方式选「传输文件」
   荣耀 / 华为手机还要打开「“仅充电”模式下允许 ADB 调试」

3. 测 iPhone：不需要装 Xcode
   用数据线连接，解锁手机点「信任此电脑」
   打开「设置 → 隐私与安全性 → 开发者模式」（打开后手机会重启）


二、启动
--------
macOS：在终端进入这个文件夹，运行  ./start.sh
Windows：双击 start.bat

第一次启动会自动安装依赖，大约一两分钟。启动后浏览器会打开 http://127.0.0.1:8765
没有手机也可以先体验：./start.sh --demo（Windows：start.bat --demo），会用一台模拟手机。


三、测一次
----------
1. 左侧选「设备」和「被测应用」（应用可以输入包名的一部分搜索）
2. 填「测试名称」，比如「录音中切后台 30 分钟」，点「开始测试」
3. 操作手机，过程中可以在上方输入框写内容后点「打标记」，比如「开始录音」「切到后台」
4. 点「结束测试」，然后到「本地记录」点「上传」
5. 打开团队服务端地址，就能看到刚才的测试；勾选多条可以做对比

左侧每一项旁边的「?」都有说明，鼠标移上去即可查看。


四、对比两次测试（不用上传，本地就能比）
----------------------------------------
1. 在「本地记录」里勾选两条或以上，先勾选的作为参照，点「对比所选」
2. 每次测试可以单独选一段时间：拖动小图下方滑块、输入「分:秒」、点常用时长（30 秒 / 1 分 / 5 分 / 10 分 / 同参照），
   或按测试中打的标记选（如从「开始录音」到「停止录音」）
3. 下方的统计表和曲线只按选中的那一段计算，变差超过阈值的标红、变好的标绿


遇到问题
--------
- 设备列表为空：确认手机已授权（Android 点「允许 USB 调试」，iPhone 点「信任」），然后点「刷新」
- iPhone 能看到但采不到数据：确认已打开「开发者模式」；第一次连接需要十几秒到半分钟
- 上传失败 / 服务端打不开：确认和服务端在同一网络
- 排查时把「本地记录 → 查看 → 复制排查信息」的内容发给我
